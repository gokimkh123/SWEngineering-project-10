# SWEngineering-project-10

소프트웨어공학 팀 프로젝트 (2026-2학기, 동아대학교 컴퓨터공학과)

> **선정 아이디어: 찰칵부산(가칭)** — 부산 여행 사진만 올리면 AI가 방문 장소를 찾고 공식 관광 데이터 근거가 붙은 여행기를 만들어 주는 서비스 ([이슈 #3](https://github.com/gokimkh123/SWEngineering-project-10/issues/3))
>
> 중간발표 문서는 [docs/](docs/) 폴더에 있고, LMS 제출본(docx·pdf)은 [docs/submission/](docs/submission/)에 있습니다. 이 README는 강의자료(1~6주차)에 나온 과제 요구사항과 일정을 정리한 것입니다.

## 1. 과제 개요

| 항목 | 내용 |
|---|---|
| 주제 | **부산 지역 안내 서비스** |
| 내용 | 부산 지역의 관광·문화·생활·교육 등의 실제 DB 및 API를 활용하여 사용자의 텍스트 또는 이미지 질의를 이해하고 적절한 정보를 제공하는 AI 기반 서비스 개발 |
| 예시 | 사용자 맞춤 부산 xxx 안내 등 |
| 팀 구성 | 4인 1조 (수강 인원에 따라 일부 조는 5인) |
| 배점 | 25% (중간발표 10% + 최종발표 15%) |
