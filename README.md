# SWEngineering-project-10

소프트웨어공학 팀 프로젝트 (2026-2학기, 동아대학교 컴퓨터공학과)

> 서비스 아이디어는 팀 회의에서 정할 예정입니다. 이 문서는 강의자료(1~5주차)에 나온 과제 요구사항과 일정만 정리했습니다.

## 1. 과제 개요

| 항목 | 내용 |
|---|---|
| 주제 | **부산 지역 안내 서비스** |
| 내용 | 부산 지역의 관광·문화·생활·교육 등의 실제 DB 및 API를 활용하여 사용자의 텍스트 또는 이미지 질의를 이해하고 적절한 정보를 제공하는 AI 기반 서비스 개발 |
| 예시 | 사용자 맞춤 부산 xxx 안내 등 |
| 팀 구성 | 4인 1조 (수강 인원에 따라 일부 조는 5인) |
| 배점 | 25% (중간발표 10% + 최종발표 15%) |

## 2. 필수 요구사항

| ID | 요구사항 | 상태 |
|---|---|---|
| REQ-01 | LLM 또는 VLM 활용 | 미정 |
| REQ-02 | 부산 지역의 관광·문화·생활·교육 등의 실제 데이터 또는 API 활용 | 미정 |
| REQ-03 | 핵심 기능 최소 3개 이상 (예: 데이터 검색, 사용자 맞춤 추천, 이미지 분석, 지도/위치 연동 등) | 미정 |
| REQ-04 | GitHub 기반 프로젝트 수행 | 진행 중 |
| REQ-05 | 소프트웨어공학에서 학습한 개발 프로세스 수행 (요구사항 분석, 아키텍처 및 상세 설계, 테스트 등). 관련 template 제공 예정 | 미정 |
| REQ-06 | 데이터 및 정보 출처 명시 | 미정 |
| REQ-07 | 저작권 및 이용조건 준수 | 미정 |
| REQ-08 | AI 도움을 받은 경우 받은 범위를 반드시 명기 (AI 활용 부분 허용) | 진행 중 ([7절](#7-ai-활용-범위-명기)) |

**제외 조건**

| ID | 제외 대상 | 비고 |
|---|---|---|
| EX-01 | 단순 LLM/VLM API 호출만으로 구성된 시스템 | |
| EX-02 | 다른 과제에서 수행 중인 프로젝트와 동일한 프로젝트 | 프로젝트 점수의 최대 50%만 인정 |
