- 계획서·요구사항분석서는 수업 SRS 템플릿 양식(표지, 문서 관리, 머리글)으로 통일했고, 각 10쪽 이내다 (계획서 8쪽, 요구사항분석서 10쪽).

- 설계서는 v1.1로 교체했다. 수업 SDD 템플릿(02_설계서(SDD)_템플릿.docx) 목차 1~12장을 모두 채웠고(21쪽), 다이어그램 7개(전체 구조, 컴포넌트, 클래스, 시퀀스 2개, 상태, 배포)를 넣었다. 그림과 원본 코드는 [04-design](../04-design/)에 있다. 3장까지만 담은 이전 제출본 v1.0(9쪽)은 git 이력(커밋 82fa2df)에 있다.
- 요구사항분석서는 김예슬 님 템플릿 양식본(v0.3)에 전규민 님 5장·10장을 넣고, 추적표 검토 결과(AC-05 수정, AC-13~17 추가)와 내용 검토 결과(FR-08 Must·FR-12 Should, 방문지 단위 정확도·평가셋, 카카오맵 운영정책, AI 모델 방침(오픈소스 VLM·저가 LLM), AI 분석 동의·여행 삭제)를 반영했다.
- 내용을 고칠 때는 원본(md 또는 docx)을 고친 뒤 제출본을 다시 만든다. v0.3 docx는 직접 고치지 않고, 제출본을 만들 때 바뀐 내용을 적용한다.
